> ⚠️ **법률 전문가 검토 전 초안이다.** 아래 결정은 사용자가 관제자에게 위임해 한국 법(전자상거래법, 콘텐츠이용자보호지침, 개인정보 보호법) 기준으로 정한 것이다. 정식 출시 전에 전문가 검토를 받는다. 이 표시는 페이지 본문(`/privacy`, `/terms`)에는 노출하지 않는다.

| 페이지 | 주소 | 내용 | 버전 |

- 스토어 등록 URL: `https://tapeletter.lab241.com/privacy`, `https://tapeletter.lab241.com/terms`

## 작성 원칙

- **이 저장소 코드가 실제로 수집·보관·전송하는 것만** 적는다. 항목마다 근거 파일은 `privacy-policy.ts` 머리 주석에 있다.
- 저장 항목, 보관 기간, 외부 전송, 가격, 정책이 바뀌면 같은 커밋에서 문서를 고치고 `version`과 페이지의 **개정 이력**(`history`)을 올린다. 시행일(`POLICY_EFFECTIVE_DATE`)도 바꾸고, 약관 2조·처리방침 11조의 고지 기간(7일, 불리한 변경 30일)을 지킨다.
- 운영자 정보(상호, 이메일 등)는 코드에 적지 않고 환경 변수로만 받는다.

## 결정 (관제자 위임, 2026-09-26)

### 결제 · 환불
1. **청약철회**: 쓰지 않은 유료 크레딧은 결제일부터 7일 안에 청약철회 가능(전자상거래법 17조). 결제는 앱 마켓이 처리하므로 환불 신청은 각 마켓의 환불 절차로 하고, 운영자는 문의 이메일로 안내·협조한다. 사용한 크레딧과 무료 크레딧은 대상이 아니다. → 약관 7조
2. **유료·무료 구분**: 서버는 한 잔액을 유지한다. 마켓 환불 알림이 오면 그 결제로 충전된 양을 잔액 안에서만 회수한다(현재 구현). 사용 순서 규칙은 두지 않는다. → 약관 7조
3. **회수 정책**: 현재대로. 잔액 안에서만 회수하고, 크레딧으로 이미 산 것은 유지한다. → 약관 7조
4. **크레딧으로 산 테이프·서랍 넓히기**: 구매 즉시 제공되는 디지털 콘텐츠로 청약철회가 제한된다(17조 2항 5호). 구매 화면에서 미리 알린다(앱 구매 시트 문구는 app 쪽에서 처리). → 약관 7조
5. **크레딧 유효기간**: 없음. 코드 변경 없음. → 약관 6조
6. **탈퇴 시 남은 크레딧**: 유료·무료 모두 소멸. 탈퇴 시트에서 미리 알리고(디자인에 있음), 7일 안의 미사용 유료분은 탈퇴 전에 마켓 환불을 신청하도록 안내한다. → 약관 13조
7. **서비스 종료**: 30일 전 공지, 쓰지 않은 유료 크레딧은 문의를 통해 환불(콘텐츠이용자보호지침). → 약관 14조

### 이용 제한 · 신고
8. **이용 제한**: 조항 유지. 관리자 도구가 없어 "운영자가 확인 후 조치" 수준, 절차는 문의 이메일 기반. → 약관 12조
9. **앱 안 신고 기능**: ~~이번에는 만들지 않는다~~ → **10단계에서 서버 API(`POST /reports`)를 만들었다**(Apple UGC 가이드라인 1.2). 신고는 앱 안 신고와 문의 이메일 두 가지로 받는다. 앱 화면은 디자인을 받은 뒤 붙인다. → 약관 11·12조

### 신고 (10단계, 2026-09-26)
- 저장: `reports`(신고자, 대상 유형·ID, 테이프면 보낸 사람 ID, 사유, 메모 300자, 상태, 시각). 녹음 파일은 복사하지 않는다.
- 탈퇴: 신고자가 탈퇴하면 `reporter_id`만 NULL(처리 이력 보관). 대상이 탈퇴해도 기록은 남는다(대상 ID는 FK 아님).
- 보관: **3년**, 매시간 정리 작업이 삭제(`ReportsService.purgeExpired`).
- 운영자 알림: 서버 로그 `warn`, `REPORT_WEBHOOK_URL`(슬랙·디스코드)에 신고 번호·사유·대상 유형만. 조회·상태 변경은 `ops/reports/reports.sh`.
- 확인 필요: 신고 기록 3년 보관은 관제자 결정이다. 법률 검토 때 함께 확인한다.

### 개인정보
10. **만 14세 미만**: 가입 대상이 아니다. 만 14세 미만으로 확인되면 계정과 정보를 삭제한다. 코드 변경 없음(서버는 나이를 받지 않는다). → 약관 3조, 처리방침 머리말·7조
11. **결제 기록 5년 뒤 파기**: **구현함.** 매시간 정리 작업이 탈퇴로 회원 연결이 끊긴(`user_id` NULL) `iap_purchases`와 `billing_events` 중 5년 지난 것을 지운다(`BillingService.purgeExpiredPaymentRecords`, e2e `test/payment-retention.e2e-spec.ts`). → 처리방침 3조
12. **아무도 받지 않은 링크 테이프**: 확정 정책 그대로(만료 뒤에도 보낸 사람이 탈퇴할 때까지 보관, 다시 공유 가능). **확인함.** → 처리방침 3조
13. **녹음 원본(raw)**: **구현함.** 변환이 성공(ready)하면 원본 파일을 지운다(`recordings.processor.ts`). 실패하면 경고 로그만 남기고 ready는 유지하며, 매시간 정리 작업(`JobsService.cleanupReadyRaw`, 한 번에 200개)이 다시 지운다. 이 작업이 원본 삭제 전에 만든 기존 ready 녹음의 원본도 한 번 정리한다(`recordings.raw_deleted_at`으로 구분). `retry`는 failed일 때만 원본을 쓰므로 영향 없음. → 처리방침 2·3조
14. **앞단 리버스 프록시 로그**: myhandball Caddyfile에 `log` 지시어가 없어 접속 로그를 남기지 않는다(관제자 확인). `cassette-edge`도 남기지 않는다. → 처리방침 3조
15. **AdMob**: 앱이 release 빌드에서 보상형 광고를 쓴다. ATT 팝업이 없어 IDFA는 받지 않고 비개인화 광고만 요청한다. 서버는 SSV 콜백(거래 ID, 광고 단위, user_id)만 받고 거래 ID와 날짜만 저장한다. → 처리방침 2·5조
16. **외부 백업(R2/B2)**: 아직 없음. "설정하면 추가" 문구 유지. → 처리방침 3조
17. **변경 고지 기간**: 7일 전, 불리한(중요한) 변경은 30일 전. → 약관 2조, 처리방침 11조
18. **분쟁 관할**: 「민사소송법」에 따른 법원. 특정 법원은 지정하지 않는다. → 약관 16조
